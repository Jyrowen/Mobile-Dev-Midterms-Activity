## Scenario Description
This console-based Dart application simulates a **Campus Coffee Shop Ordering System** that calculates gross subtotals, evaluates VIP discount eligibility, computes loyalty points, and prints a formatted receipt summary.

---

## Technical Highlights
- **Explicit Data Types:** Uses explicit `int`, `double`, `String`, and `bool` variables (no `var` or `dynamic`).
- **Operators:** Applies arithmetic operators (`*`, `~/`, `%`) and comparison operators (`>=`, `==`).
- **Formatted Output:** Employs string interpolation (`$variable` and `${expression}`) for labeled, human-readable terminal output.
